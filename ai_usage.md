# AI Usage

AI (commercial LLMs) was used without specific skills or MCPs. AI was used to

- extract locators from the page html
- provide a plan for page keywords and implement (with changes)
- construct the user and product data in python variable files (necessary information available from previous tasks)
- write the initial login test cases based on test names
- re-write login tests from testing one specific user to cover all cases
- review manually written shopping flow test case
- write smaller fixes that were needed based on the test runs

For future, I would add separate skills (extract locator, review test case etc.) to make prompting easier, automate the review, and to share common way of working.
